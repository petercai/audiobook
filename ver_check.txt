- torch==2.8.*
- torchaudio==2.8.*
- torchvision==0.23.* (matches torch 2.8)
- torchcodec==0.7.* (matches torch 2.8; requires FFmpeg 4-7 on PATH)
pyannote version alignment (with torch 2.8):
- pyannote-audio==4.* (current 4.0.3)
- pyannote-core==6.*, pyannote-metrics==4.*, pyannote-pipeline==4.* (these match pyannote-audio 4.x)

Why the error happened:
torchcodec failed to load its FFmpeg-backed DLLs, which usually means FFmpeg is missing/not on PATH or the torchcodec build does not match the installed torch build.


Reinstall torchcodec from the same channel/build as torch (CPU vs CUDA) so the versions match:
- CPU: `python -m pip install --force-reinstall --index-url https://download.pytorch.org/whl/cpu torchcodec==0.7.*`
- CUDA: `python -m pip install --force-reinstall --index-url https://download.pytorch.org/whl/cu121 torchcodec==0.7.*` (swap `cu121` to match your torch build, e.g. `cu118`, `cu124`)

pyannote/audio warning cause:
- pyannote uses torchcodec for decoding; the warning is torchcodec failing to load FFmpeg DLLs.
- Fix by installing FFmpeg 4-7 on PATH and reinstalling torchcodec from the same torch channel/build (CPU vs CUDA).
- Alternative: pass preloaded audio dicts to pyannote to bypass torchcodec.

Chocolatey downgrade to FFmpeg 7:
- choco list ffmpeg --all-versions
- choco uninstall ffmpeg -y
- choco install ffmpeg --version=7.1.1 -y
